# NOVA DEALS — E-commerce Black Friday 2026

NOVA DEALS est une boutique e-commerce haute performance et conversion-driven spécialement conçue pour la campagne Black Friday 2026.

## Points Forts & Fonctionnalités

- **Conversion-Driven UX :** Compte à rebours temps réel, offres flash avec décompte individuel, jauge de stock dynamique, floating deal badges.
- **Catalogue & Navigation :** Filtrage multi-critères (univers, budget, tri par remise, recherche instantanée en direct).
- **Fiche Produit Immersive :** Galerie interactive, sélecteur de finitions/couleurs, avis clients, ajout au panier express.
- **Panier Latéral (Cart Drawer) :** Slide-over fluide avec gestion des quantités, codes promotionnels cumulables (`BLACK10`, `NOVA20`), calcul dynamique des économies.
- **Checkout Réaliste en 3 Étapes :** Coordonnées, livraison express, simulation de paiement sécurisé.
- **Confirmation d'Achat :** Numéro de commande `#NOVA-XXXXX` généré, suivi logistique et animation de célébration vectorielle.
- **Design System & A11y :** Thème dark premium (#080A0F), typographie Inter, respect strict de `prefers-reduced-motion` et conformité Zéro Émoji (icônes vectorielles Lucide React exclusivement).

## Stack Technique

- **Framework :** React 18 + Vite + TypeScript
- **Styling :** Tailwind CSS
- **Animations :** Framer Motion
- **State Management :** Zustand
- **Icônes :** Lucide React (100% vectoriel, aucun émoji)
- **Effets :** Canvas-Confetti

## Démarrage Rapide

```bash
# Installation des dépendances
npm install

# Lancement en mode développement
npm run dev

# Construction de la version de production
npm run build
```
